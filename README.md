## Repo các nội dung train cho xử lý tín hiệu và AI cơ bản

Repo chứa các tài liệu training (bao gồm slide và code) SPARC Lab về lĩnh xử lý tín hiệu và AI.


Hiện tại có các nội dung:
1. Code mẫu của các thư viện thường dùng cho scientific computing (numpy, pandas, matplotlib) 

2. AI cơ bản - tự dựng lại một số thuật toán cổ điển
- Linear Regression
- Softmax Regression
- Autograd và MLP (dựa vào Micrograd)
- CNN
